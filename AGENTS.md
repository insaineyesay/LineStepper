# Read PROGRESS.md first

[PROGRESS.md](PROGRESS.md) is the shared, living context for this repo: what's
built and live, what's left, how things fit together, and the working rules.
Read it before any task. **Every PR that changes the app, backend,
infrastructure, plan or a decision must update PROGRESS.md in the same PR**
(and CHANGELOG.md). If something in it is wrong, fix it.
